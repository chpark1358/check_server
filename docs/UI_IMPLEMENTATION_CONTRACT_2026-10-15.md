## API 또는 운영 정책이 필요한 별도 항목

아래 항목은 화면을 완성한 것처럼 보이게 하기 위해 가상의 동작이나 수치를 추가하지 않는다. UI 전체 구조 적용과 별개로 명확하게 남기는 기능 의존성이다.

| 항목 | 현재 경계 | 후속 구현에 필요한 것 |
| --- | --- | --- |
| 통합 작업 타임라인 | 개별 기록 ID와 실제 제공된 관계만 사용; 없는 통합 작업 ID를 생성하지 않음 | 점검·문서·발송을 잇는 작업 식별자와 관계 저장 정책 |
| PDF만 재시도 | 기존 문서 생성 흐름과 DOCX 성공 결과를 유지; 전용 PDF 재시도가 있는 것처럼 표시하지 않음 | 기존 documentId 갱신 또는 새 버전 생성 정책, 변환 전용 API |
| 장기 보관 정책 | 이력의 조회 기간과 문서 사용 만료를 구별; 임의로 보관·삭제 기간을 변경하지 않음 | 업무 보관 기준, DB·Storage 보관/삭제 작업, 감사·복구 정책 |
| 관리자 전수 검색·집계 | 최근 표본 조회 한계와 표본 내 필터·페이지 이동을 명시 | 서버 조건 검색, 전수 집계 및 커서 페이지 API |
